# NovaLink Africa

> Connecting Africa. Empowering Futures.

Marketing landing page for NovaLink Africa — a venture delivering affordable, high-speed connectivity to universities, rural communities, and commercial partners across the continent.

## Why this exists

This is the public-facing site introducing NovaLink Africa's mission and connectivity offering. It's one piece of a larger NovaLink project:
- [`NovaLinkAfrica-App`](https://github.com/GeraldBonsu/NovaLinkAfrica-App) — the NovaLink OS product prototype (campus WiFi access + wallet)
- [`NovaLinkAfrica-Website`](https://github.com/GeraldBonsu/NovaLinkAfrica-Website) — an earlier combined workspace bundling this site with an in-progress app build
- [`NovaLinkAfrica-OutreachAgentVersion1`](https://github.com/GeraldBonsu/NovaLinkAfrica-OutreachAgentVersion1) — the lead-generation automation used for business development, unrelated to the site/app split

## Tech stack

Static HTML/CSS with React loaded via CDN for interactive sections (no build step).

## Running locally

Open `index.html` directly, or serve the directory with any static file server.

Live: https://novalink-africa-website.vercel.app
